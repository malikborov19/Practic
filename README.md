# Консольная система учета студентов

Учебный проект консольного приложения на Java для автоматизации учета студентов колледжа с использованием объектно-ориентированного программирования (ООП).

## 🛠 Стек технологий
* **Язык:** Java SE
* **Коллекции:** ArrayList
* **Работа с файлами:** File I/O (поддержка сохранения в форматы TXT/CSV)
* **Архитектура:** ООП (Инкапсуляция, разделение на слои Model-Repository-Service)

## 🚀 Реализованный функционал
* **Полный CRUD:** добавление, просмотр, редактирование и удаление студентов по ID.
* **Поиск и сортировка:** быстрый поиск по фамилии, сортировка списка по алфавиту и по среднему баллу.
* **Сохранение данных:** автоматическая загрузка базы данных при старте программы и сохранение изменений в текстовый файл.
* **Безопасность:** валидация пользовательского ввода и обработка исключений (try-catch).
